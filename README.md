# Glimmerstones — мерцающие камни

Спокойная игра-сортировка камней. Перекладывай сверкающие камни по полочкам,
собирай тройки — и они улетают в картинку, засыпая её камешками.
Без таймеров, жизней, рекламы, покупок, регистрации и интернета. Любой ход можно отменить.

**Играть:** https://sogener.github.io/glimmerstones/

## Как установить на главный экран

### iPhone / iPad (Safari)
1. Открой ссылку выше **в Safari** (не в Chrome и не во встроенном браузере Telegram/Instagram).
2. Нажми кнопку **«Поделиться»** — квадрат со стрелкой вверх (внизу экрана на iPhone).
3. Пролистай вниз и выбери **«На экран «Домой»»**.
4. Нажми **«Добавить»**. На экране появится иконка с розовым сердечком.
5. Запусти игру с иконки: она откроется во весь экран и будет работать без интернета.

Важно: на iPhone игра на экране «Домой» хранит прогресс отдельно от вкладки Safari.
Лучше сразу установить и играть с иконки.

### Android (Chrome)
1. Открой ссылку в **Chrome**.
2. Нажми **⋮** (меню справа сверху) → **«Установить приложение»**
   (или **«Добавить на главный экран»**). Иногда Chrome сам предложит установку внизу экрана.
3. Подтверди. Игра появится среди приложений и будет работать без интернета.

На стартовом экране игры есть кнопка «Добавить на экран «Домой»» с подсказкой для твоего телефона.

## Как играть
- Тап по камню — он приподнимается. Тап по полочке со свободным местом — камень перелетает.
  Можно и просто перетащить пальцем.
- Три одинаковых камня на полочке сливаются и улетают в картинку.
- Когда полочка опустела, вперёд выезжает следующий ряд (он виден затемнённым заранее).
- Если место кончилось — отмени ход, добавь полочку (раз за уровень) или начни заново.
- «Подсказка» покажет хороший ход; если путь уже не сложится, предложит вернуться на пару ходов.
- Собранные картинки сохраняются в «Галерее».

## Для разработки
```bash
npm install
npm run dev -- --host   # открыть с телефона в той же Wi-Fi сети по адресу из консоли
npm test                # юнит-тесты (Vitest)
npm run build           # генерация уровней + проверка типов + сборка в dist/
npm run levels          # только перегенерировать уровни (src/data/levels.json)
npm run icons           # перерисовать иконки (нужен Playwright с Chromium)
```
Своя картинка: положи JSON в `src/pictures/` (формат описан в `CLAUDE.md`) и выполни `npm run levels`.
Деплой на GitHub Pages — автоматически при пуше в `main` (`.github/workflows/deploy.yml`).
